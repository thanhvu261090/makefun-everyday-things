## The entry

> A toaster is a tiny elevator for bread that takes it down into a hot basement and brings it back up brown and crispy.
> It maps the down-and-up trip and the heat turning pale bread brown, but it leaves out the timer that ends the ride and the fact that nobody is driving.

Line 1 explains a toaster to a 10-year-old in a single vivid sentence built
on one analogy: a tiny elevator for bread. Line 2 says in one sentence why
that analogy works — what it maps (the down-and-up trip, the heat turning
pale bread brown) and what it leaves out (the timer, and that nobody is
driving).

## How it works

`main.py` holds the entry text as a string constant, checks it against the
competition gate (UTF-8 text, 1–400 characters, not only whitespace, exactly
two lines, one sentence per line), then writes it exactly as-is to
`/output/entry.txt`.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
